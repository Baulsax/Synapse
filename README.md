# Synapse

Synapse is a Windows desktop application for creating and running automation workflows through a visual block editor.

Rather than writing scripts by hand, you can build workflows by connecting blocks together. Use them to automate keyboard and mouse input, work with variables, build logic and loops, and create interactive interfaces for your workflows.

The goal is to make automation easier to create, manage, and share.

## Features

- **Visual Workflow Editor:** Build workflows by dragging and connecting blocks.
- **Keyboard Automation:** Press and hold keys, type text, and listen for keyboard input.
- **Mouse Automation:** Move the mouse, perform clicks, and control scrolling.
- **Variables and Logic:** Store values, perform calculations, and control workflow behavior.
- **Loops and Functions:** Repeat actions and organize reusable pieces of logic.
- **Input Triggers:** Start, stop, and control workflows using configurable inputs.
- **Workflow UI:** Create windows, labels, and buttons that can interact with your workflows.
- **Workflow Management:** Organize, import, export, and run your workflows.
